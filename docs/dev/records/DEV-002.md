## Historical fact

DEV-002 曾物化 D-040 的十项 deterministic Intent mechanism qualification contracts、public/private controls、
review assignments 和 requalification plans。用户也完成了当时定义的独立审查。Git history 保留这些事实，
但它们没有 qualification 任何真实 implementation，也没有被 production consumer 使用。

## Why superseded

这套工作发生在 Cairn 证明 runtime DeepSeek SIR 对迁移有价值之前。它把 future Admission/Gate 所需的
independence 和 qualification ceremony 错误前置到一个 evaluator fixture 上，扩大了 case-specific testkit，
却没有运行逐任务模型、没有证明 cross-task generalization，也没有产生 downstream migration value。

D-042 改为：先通过现有 agent runtime 做最小 proposal-only SIR workflow；用第二个不同 task 和 downstream
utility 做 go/no-go；只有出现真实 verdict-relevant consumer 后，才围绕 exact mechanism 实现对应
qualification。
